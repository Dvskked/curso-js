Modulo 01

Fundamentos de JavaScript

En este modulo aprenderas los cimientos de todo programa en JavaScript. Comenzaremos con las variables, los tipos de datos y las operaciones basicas que son la base para todo lo demas que aprenderas en este curso.

1.1 Variables: var, let y const

JavaScript ofrece tres formas de declarar variables: var, let y const. Cada una tiene un comportamiento diferente en cuanto a alcance, elevacion (hoisting) y reasignacion.

La variable var (legado)

var es la forma antigua. Tiene alcance de funcion, accesible desde cualquier lugar dentro de la funcion donde se declaro. 

// var: alcance de funcion (no recomendado en codigo moderno)
var nombre = "Ana";
var edad = 25;
var activo = true;

// Problema con var: se escapa del bloque
if (true) {
  var mensaje = "Hola";
}
console.log(mensaje); // "Hola" - var no respeta el bloque

La variable let (recomendada)

let tiene alcance de bloque. Solo es accesible dentro del bloque {} donde se declaro. Ideal para valores que cambian. 

// let: alcance de bloque (recomendado para valores que cambian)
let contador = 0;
let nombreUsuario = "Carlos";

if (true) {
  let temporal = "Solo existe aqui";
  console.log(temporal); // "Solo existe aqui"
}
// console.log(temporal); // ReferenceError

// let permite reasignacion
contador = 1;
contador = 2; // Perfectamente valido

La constante const (recomendada)

const tiene alcance de bloque pero su valor no puede ser reasignado. Es la forma recomendada por defecto. 

// const: no reasignable (recomendado por defecto)
const PI = 3.14159;
const API_URL = "https://api.ejemplo.com";
const MAX_INTENTOS = 3;

// PI = 3.14; // TypeError: Assignment to constant variable.

// Importante: const no significa "inmutable"
const usuario = { nombre: "Luis", edad: 30 };
usuario.edad = 31; // Se puede modificar propiedades
// usuario = {}; // Pero no se puede reasignar la referencia

✗ Uso incorrecto de var

for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // Imprime 3, 3, 3
  }, 1000);
}
// var tiene alcance de funcion, no de bloque

✓ Uso correcto de let

for (let i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // Imprime 0, 1, 2
  }, 1000);
}
// let crea una nueva variable en cada iteracion
Regla de oro: Usa const por defecto. Cambia a let solo cuando necesites reasignar. Nunca uses var en codigo moderno.
Ejercicio Practico: Declara variables con const para tu nombre, apellido y edad. Intenta reasignar cada una y observa los errores. Luego crea una variable let para un contador y aumentala de 1 en 1 hasta llegar a 10.

1.2 Tipos de Datos en JavaScript

JavaScript es un lenguaje de tipado dinamico. El tipo se determina en tiempo de ejecucion. Tiene 8 tipos, divididos en primitivos y no primitivos.

Tipos Primitivos

// Los tipos primitivos de JavaScript
let texto = "Hola Mundo";           // string
let entero = 42;                    // number
let decimal = 3.14;                  // number
let verdadero = true;                // boolean
let nada = null;                    // null
let indefinido;                       // undefined
let id = 9007199254740991n;          // bigint
let simbolo = Symbol("id");         // symbol

El operador typeof

// typeof devuelve el tipo como string
console.log(typeof "Hola");       // "string"
console.log(typeof 42);          // "number"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object" (bug historico!)
console.log(typeof [1, 2, 3]);    // "object"
console.log(typeof {});          // "object"
Cuidado: typeof null devuelve "object" en lugar de "null". Es un bug historico que nunca se corrigio.

Diferencia entre undefined y null

// undefined: asignado automaticamente por JavaScript
let edad;
console.log(edad);           // undefined
console.log(typeof edad);  // "undefined"

// null: ausencia intencional de valor
let resultado = null;
console.log(resultado);      // null

// Funcion que busca un usuario
function buscarUsuario(id) {
  const usuario = usuarios.find(u => u.id === id);
  return usuario || null; // null si no encontro
}

✗ Confusion con tipos

let precio = "100";  // Es string!
let total = precio + 50;
console.log(total);     // "10050"

✓ Uso correcto

let precio = 100;  // number
let total = precio + 50;
console.log(total);     // 150

1.3 Operadores en JavaScript

Los operadores son simbolos que realizan operaciones sobre valores. JavaScript tiene aritmeticos, asignacion, comparacion y logicos.

Operadores Aritmeticos

let a = 10;
let b = 3;

console.log(a + b);   // 13    (suma)
console.log(a - b);   // 7     (resta)
console.log(a * b);   // 30    (multiplicacion)
console.log(a / b);   // 3.333 (division)
console.log(a % b);   // 1     (modulo)
console.log(a ** b);  // 1000  (potencia)

let contador = 5;
contador++;       // 6
contador--;       // 5
let nuevo = ++contador; // pre-incremento

Operadores de Comparacion

// == vs === (abstracta vs estricta)
console.log(5 == "5");     // true  (convierte tipos)
console.log(5 === "5");    // false (mismos tipos)
console.log(0 == "");      // true  (inesperado)
console.log(0 === "");     // false (correcto)

// != vs !==
console.log(5 != "5");     // false
console.log(5 !== "5");    // true
Siempre usa === (igualdad estricta): == convierte tipos antes de comparar, causando resultados inesperados.

Operadores Logicos

// AND (&&): ambas deben ser true
console.log(true && true);    // true
console.log(true && false);   // false

// OR (||): al menos una true
console.log(true || false);   // true

// NOT (!): invierte
console.log(!true);            // false

// Valores por defecto con ||
const nombre = "" || "Visitante";
console.log(nombre);  // "Visitante"

✗ Usando ==

let edad = "0";
if (edad == 0) {
  console.log("Sin edad");
}
// Se ejecuta porque "0" == 0

✓ Usando ===

let edad = "0";
if (edad === 0) {
  console.log("Sin edad");
}
// No se ejecuta: string !== number
Ejercicio: Resuelve: true && "hello", false || 42, !"", 0 || "fallback". Escribe un programa que determine si un numero es par.

1.4 Strings: Manipulacion de Texto

Los strings se crean con comillas simples, dobles o backticks. Tienen metodos incorporados para manipular texto.

Creacion de Strings

// Tres formas de crear strings
const str1 = "Hola con comillas dobles";
const str2 = 'Hola con comillas simples';
const str3 = `Hola con backticks`;

// Backticks: interpolacion y multil̒nea
const nombre = "Mundo";
const saludo = `Hola ${nombre}!`;
console.log(saludo);  // "Hola Mundo!"

Metodos de String

const texto = "JavaScript es increible";

console.log(texto.length);           // 22
console.log(texto.toUpperCase());    // "JAVASCRIPT ES INCREIBLE"
console.log(texto.toLowerCase());    // "javascript es increible"
console.log(texto.includes("Script"));  // true
console.log(texto.indexOf("es"));      // 11
console.log(texto.startsWith("Java")); // true
console.log(texto.endsWith("ble"));   // true
console.log(texto.slice(0, 10));      // "JavaScript"
console.log(texto.slice(-9));          // "increible"

Busqueda y Reemplazo

const mensaje = "Me gusta Python y JavaScript";

console.log(mensaje.replace("Python", "JS"));
// "Me gusta JS y JavaScript"

const todos = "aabbcc".replaceAll("a", "x");
console.log(todos);  // "xxbbcc"

const csv = "manzana,pera,banana";
const frutas = csv.split(",");
console.log(frutas);  // ["manzana", "pera", "banana"]

const unido = frutas.join(" - ");
console.log(unido);   // "manzana - pera - banana"
Inmutabilidad: Los strings son inmutables. toUpperCase() devuelve un nuevo string, no modifica el original.
Ejercicio: Escribe una funcion que reciba un nombre completo y devuelva: (1) en mayusculas, (2) iniciales por puntos, (3) longitud, (4) apellido en reversa.

1.5 Numbers y Operaciones Numericas

Todos los numeros en JavaScript son del tipo number (IEEE 754 doble precision). No hay distincion entre int y float.

Valores Especiales

const inf = Infinity;       // Infinity
const nInf = -Infinity;      // -Infinity
const nan = NaN;              // NaN (Not a Number)

// NaN aparece con operaciones invalidas
console.log("hola" * 2);      // NaN
console.log(0 / 0);            // NaN

// Verificar NaN
console.log(Number.isNaN(NaN));  // true
console.log(NaN === NaN);            // false (por diseno)

Conversion de Numeros

console.log(Number("42"));        // 42
console.log(Number("3.14"));      // 3.14
console.log(Number(""));           // 0
console.log(Number("hola"));       // NaN

console.log(parseInt("42.9"));     // 42 (trunca)
console.log(parseInt("100px"));     // 100
console.log(parseFloat("3.14abc")); // 3.14

console.log(+"42");    // 42 (operador unary)

Metodos de Numero

console.log(Math.round(4.5));     // 5
console.log(Math.ceil(4.1));      // 5 (hacia arriba)
console.log(Math.floor(4.9));     // 4 (hacia abajo)

console.log((19.995).toFixed(2));  // "20.00" (string!)

console.log(Math.random());        // 0.0 - 1.0
const dado = Math.floor(Math.random() * 6) + 1;
console.log(dado);                 // 1 - 6

console.log(Math.min(5, 3, 8, 1));  // 1
console.log(Math.max(5, 3, 8, 1));  // 8
Precision: 0.1 + 0.2 no es exactamente 0.3. El resultado es 0.30000000000000004 por IEEE 754.
Ejercicio: Juego de adivinanza: numero aleatorio 1-100, 5 intentos, mostrar "mayor"/"menor", contar intentos.

1.6 Booleans, null y undefined

Los booleans solo tienen true y false. JavaScript tiene truthy y falsy.

Valores Truthy y Falsy

// Solo estos 8 valores son falsy
console.log(Boolean(false));       // false
console.log(Boolean(0));             // false
console.log(Boolean(0n));            // false (BigInt cero)
console.log(Boolean(""));            // false (string vacio)
console.log(Boolean(null));          // false
console.log(Boolean(undefined));     // false
console.log(Boolean(NaN));            // false

// Todo lo demas es truthy
console.log(Boolean("0"));    // true
console.log(Boolean([]));     // true
console.log(Boolean({}));     // true

null vs undefined

// undefined: asignado automaticamente
let nombre;
console.log(nombre);           // undefined
console.log(typeof nombre);  // "undefined"

// null: ausencia intencional de valor
let usuario = null;
console.log(usuario);          // null
console.log(typeof usuario);   // "object" (bug)

// Verificar correctamente
console.log(usuario === null); // true

✗ Confusion truthy/falsy

const edad = "0";
if (edad) {
  console.log("Tiene edad");
}
// "0" es truthy!

✓ Comparacion explicita

const edad = "0";
if (edad !== undefined && edad !== "") {
  console.log("Tiene edad");
}

1.7 Type Coercion: Conversion Automatica

Type coercion es la conversion implicita de tipos que JavaScript hace durante operaciones.

Coercion Explicita vs Implicita

// EXPLICITA: tu haces la conversion
const num = Number("42");    // 42
const str = String(42);        // "42"
const bool = Boolean(1);       // true

// IMPLICITA: JavaScript lo hace solo
console.log("5" - 2);     // 3  (string a number)
console.log("5" + 2);     // "52" (concatenacion!)
console.log("5" * 2);     // 10 (string a number)
El + es especial: Con un string, + concatena. "5" + 2 es "52", no 7.

Coercion en Comparaciones

// == convierte tipos
console.log(1 == "1");       // true
console.log(0 == "");        // true
console.log(0 == false);     // true

// === NO convierte
console.log(1 === "1");      // false
console.log(0 === "");       // false
console.log(0 === false);    // false

✗ Inesperados con ==

console.log("" == false);   // true
console.log("0" == false);  // true
console.log([] == false);   // true

✓ Seguros con ===

console.log("" === false);  // false
console.log("0" === false); // false
console.log([] === false);  // false

Tabla de Conversion a Number

console.log(Number("42"));          // 42
console.log(Number(""));             // 0
console.log(Number(true));           // 1
console.log(Number(false));          // 0
console.log(Number(null));           // 0
console.log(Number(undefined));      // NaN
Ejercicio: Predice: "10" - 5, "10" + 5, true + 1, false + "", null + 1, undefined + 1. Crea convertirEdad(edad).

1.8 Template Literals y Console Debugging

Los template literals usan backticks y permiten interpolacion, strings multil̒nea y expresiones.

Interpolacion de Variables

// Antes de ES6
const nombre = "Ana";
const msg = "Hola " + nombre + ", tienes 25 anios";

// Con ES6: template literals
const msg2 = `Hola ${nombre}, tienes ${25} anios`;

// Expresiones en ${}
const precio = 150;
const total = `Total: $${precio * 1.19}`;
console.log(total);  // "Total: $178.5"

// Funciones en ${}
console.log(`${"mundo".toUpperCase()}!`);  // "MUNDO!"

Strings Multil̒nea

const usuarios = ["Ana", "Luis", "Carlos"];
const lista = `
  <ul>
    ${usuarios.map(u => `<li>${u}</li>`).join("\n    ")}
  </ul>
`;
console.log(lista);

Metodos de Console

// console.log: basico
console.log({ nombre: "Pedro", edad: 30 });

// console.table: tabla
const productos = [
  { nombre: "Laptop", precio: 999 },
  { nombre: "Mouse", precio: 25 }
];
console.table(productos);

// console.group: agrupar
console.group("Config");
console.log("Tema: oscuro");
console.groupEnd();

// console.time: medir tiempo
console.time("bucle");
for (let i = 0; i < 1000000; i++) {}
console.timeEnd("bucle");

console.warn("Version deprecada");
console.error("Error de conexion");
Tip: Usa console.table() para inspeccionar arrays de objetos. Filtra columnas: console.table(data, ['name', 'price']).

Estructuras de Control

Las estructuras de control determinan el flujo de ejecucion de tu programa. Aprenderas a tomar decisiones con condicionales y a repetir acciones con bucles.

2.1 Condicionales: if, else if, else

La sentencia if ejecuta un bloque de codigo si una condicion es truthy. Puedes encadenar else if y else para manejar multiples caminos.

Estructura Basica

const edad = 18;

if (edad >= 18) {
  console.log("Eres mayor de edad");
} else {
  console.log("Eres menor de edad");
}
// "Eres mayor de edad"

Encadenar multiples condiciones

const nota = 75;

if (nota >= 90) {
  console.log("Excelente");
} else if (nota >= 70) {
  console.log("Bueno");
} else if (nota >= 50) {
  console.log("Regular");
} else {
  console.log("Reprobado");
}
// "Bueno"

Combinar condiciones con && y ||

const usuario = { activo: true, admin: false };

if (usuario.activo && usuario.admin) {
  console.log("Admin activo");
} else if (usuario.activo || usuario.admin) {
  console.log("Activo o admin");
} else {
  console.log("Sin acceso");
}
// "Activo o admin"
Cuidado con la negacion: !usuario.activo && !usuario.admin es dificil de leer. Prefiere !(usuario.activo || usuario.admin).

✗ Asignacion accidental

const x = 0;
if (x = 5) {  // Asignacion, no comparacion!
  console.log("Siempre ejecuta");
}

✓ Comparacion estricta

const x = 0;
if (x === 5) {
  console.log("Solo si x es 5");
}

2.2 Sentencia switch

switch evalua una expresion y ejecuta el caso que coincida. Cada caso requiere break.

Uso Basico

const dia = "lunes";

switch (dia) {
  case "lunes":
  case "martes":
  case "miercoles":
  case "jueves":
  case "viernes":
    console.log("Dia laboral");
    break;
  case "sabado":
  case "domingo":
    console.log("Fin de semana");
    break;
  default:
    console.log("Dia invalido");
}
No olvides break: Sin break, el switch "cae" al siguiente caso (fall-through). A veces util, pero usualmente un error.

Switch con expresiones

const hora = 14;

switch (true) {
  case (hora < 12):
    console.log("Buenos dias");
    break;
  case (hora < 18):
    console.log("Buenas tardes");
    break;
  default:
    console.log("Buenas noches");
}

✗ Sin break

const tipo = "admin";
switch (tipo) {
  case "admin":
    console.log("Admin");
  case "user":   // fall-through!
    console.log("User");
}

✓ Con break

const tipo = "admin";
switch (tipo) {
  case "admin":
    console.log("Admin");
    break;
  case "user":
    console.log("User");
    break;
}
Ejercicio: Crea calcularOperacion(a, b, operador) con switch que soporte +, -, *, /, %. Incluye validacion de division por cero.

2.3 Operador Ternario

El operador ternario es un if/else en una linea: condicion ? valorSiTrue : valorSiFalse.

Sintaxis basica

const edad = 20;
const estado = edad >= 18 ? "adulto" : "menor";
console.log(estado);  // "adulto"

// Es equivalente a:
let estado2;
if (edad >= 18) {
  estado2 = "adulto";
} else {
  estado2 = "menor";
}

Ternarios anidados

const nota = 85;
const resultado = nota >= 90 ? "A"
  : nota >= 80 ? "B"
  : nota >= 70 ? "C"
  : "F";
console.log(resultado);  // "B"

✗ Ternarios complejos

// Dificil de leer
const x = a > b ? (c > d ? e : f) : (g ? h : i);

✓ if/else para logica compleja

// Mejor: if/else para logica compleja
let x;
if (a > b) {
  x = c > d ? e : f;
} else {
  x = g ? h : i;
}
Regla: Usa ternarios para decisiones simples en una linea. Para logica compleja, usa if/else.
Ejercicio: Escribe saludo(nombre, hora) con ternario que retorne "Buenos dias", "Buenas tardes" o "Buenas noches".

2.4 Bucle for clasico

El bucle for repite un bloque un numero determinado de veces.

Estructura del for

// for (inicio; condicion; incremento)
for (let i = 0; i < 5; i++) {
  console.log(i);
}
// 0, 1, 2, 3, 4

Patrones comunes

// Contar hacia atras
for (let i = 10; i >= 0; i -= 2) {
  console.log(i);  // 10, 8, 6, 4, 2, 0
}

// Multiplicar
for (let i = 1; i <= 10; i++) {
  console.log(`5 x ${i} = ${5 * i}`);
}
Evita var en for: Usa let para evitar problemas de alcance con closures y callbacks como setTimeout.
Ejercicio: Escribe un bucle que imprima todos los numeros pares del 1 al 50. Luego uno que imprima los multiplos de 3.

2.5 Bucles while y do-while

Los bucles while y do-while repiten mientras la condicion sea truthy.

while basico

let contador = 0;
while (contador < 5) {
  console.log(contador);
  contador++;
}
// 0, 1, 2, 3, 4

do-while: ejecuta al menos una vez

let intento = 0;
do {
  intento++;
  console.log(`Intento ${intento}`);
} while (intento < 3);

Ejemplo practico: juego

const secreto = 42;
let intentos = 0;
let adivinado = false;

while (!adivinado && intentos < 3) {
  intentos++;
  const intento = Math.floor(Math.random() * 100);
  if (intento === secreto) {
    adivinado = true;
  }
}
Cuidado con el bucle infinito: Si la condicion nunca es falsa, el programa se cuelga. Siempre asegurate que la variable de control cambie.

✗ Bucle infinito

let i = 0;
while (i < 5) {
  console.log(i);
  // Olvide incrementar i!
}

✓ Incremento correcto

let i = 0;
while (i < 5) {
  console.log(i);
  i++;  // Siempre incrementa
}
Ejercicio: Escribe factorial(n) con while. Luego un contador regresivo de 10 a 0 con do-while.

2.6 Bucle for...of (iterables)

for...of recorre los valores de cualquier iterable (arrays, strings, Map, Set).

Recorrer arrays

const frutas = ["manzana", "pera", "banana"];

for (const fruta of frutas) {
  console.log(fruta);
}
// "manzana", "pera", "banana"

Recorrer strings

const palabra = "Hola";
for (const letra of palabra) {
  console.log(letra);
}
// "H", "o", "l", "a"

Con entries() para tener indice

const notas = [90, 75, 85, 60];
for (const [indice, nota] of notas.entries()) {
  console.log(`${indice}: ${nota}`);
}
// "0: 90", "1: 75", "2: 85", "3: 60"

✗ for...in en arrays

const arr = [1, 2, 3];
for (var i in arr) {
  console.log(arr[i]); // tipo string!
}

✓ for...of en arrays

const arr = [1, 2, 3];
for (const val of arr) {
  console.log(val); // tipo number
}
for...of vs for...in: for...of recorre valores, for...in recorre propiedades/indices.
Ejercicio: Dado [10, 25, 30, 15, 40], usa for...of para encontrar el mayor, calcular el promedio y contar los mayores a 20.

2.7 Bucle for...in (propiedades)

for...in recorre las propiedades enumerables de un objeto. Ideal para objetos, no para arrays.

Recorrer objetos

const usuario = {
  nombre: "Carlos",
  edad: 30,
  email: "carlos@email.com"
};

for (const clave in usuario) {
  console.log(`${clave}: ${usuario[clave]}`);
}
// "nombre: Carlos", "edad: 30", "email: carlos@email.com"

Verificar propiedades con hasOwnProperty

const prototype = { tipo: "animal" };
const gato = Object.create(prototype);
gato.nombre = "Mishi";

for (const clave in gato) {
  if (gato.hasOwnProperty(clave)) {
    console.log(`${clave}: ${gato[clave]}`);
  }
}
// Solo "nombre: Mishi" (no incluye "tipo")

✗ for...in en arrays

const arr = [10, 20, 30];
for (const i in arr) {
  console.log(i, arr[i]);
}
// i es "0", "1", "2" (strings!)

✓ for...of + entries()

const arr = [10, 20, 30];
for (const [i, val] of arr.entries()) {
  console.log(i, val);
}
// i es 0, 1, 2 (numbers)
Regla: Usa for...of para arrays/strings. Usa for...in para objetos.
Ejercicio: Dado {a: 1, b: 2, c: 3}, calcula la suma de valores, crea un nuevo objeto con valores duplicados, cuenta las propiedades.

2.8 break y continue

break termina el bucle. continue salta a la siguiente iteracion.

break: salir del bucle

// Encontrar el primer multiplo de 7
const numeros = [2, 5, 8, 14, 21, 30];
for (const num of numeros) {
  if (num % 7 === 0) {
    console.log(`Primer multiplo: ${num}`);
    break;
  }
}
// "Primer multiplo: 14"

continue: saltar iteracion

// Imprimir solo impares
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);  // 1, 3, 5, 7, 9
}

Etiquetas (labels) para bucles anidados

// break solo sale del bucle mas interno
externo:
for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break externo;
    console.log(`${i},${j}`);
  }
}
// "0,0", "0,1", "0,2", "1,0"

✗ Condicional envolvente

for (let i = 0; i < 100; i++) {
  if (i % 2 === 0) {
    console.log(i);
  }
}

✓ Continue para early exit

for (let i = 0; i < 100; i++) {
  if (i % 2 !== 0) continue;
  console.log(i);
}
Ejercicio: Busca el primer numero divisible por 3 y 5 en [7, 12, 15, 20, 25, 30] con break. Filtra solo positivos con continue.

Funciones

Las funciones son bloques de codigo reutilizables. En este modulo aprenderas a crearlas, pasarles parametros, entender closures y usarlas como callbacks.

3.1 Declaracion de Funciones

Una funcion es un bloque de codigo que ejecuta una tarea. Se define con function y se invoca con ().

Sintaxis basica

// Declaracion de funcion
function saludar() {
  console.log("Hola, mundo!");
}

saludar();  // Invocar / llamar
saludar();  // Puedes llamarla muchas veces

Parametros y retorno

function sumar(a, b) {
  return a + b;
}

const resultado = sumar(5, 3);
console.log(resultado);  // 8

// Sin return, la funcion retorna undefined
function saludar2(nombre) {
  console.log(`Hola ${nombre}`);
}
const res = saludar2("Ana");
console.log(res);  // undefined

Hoisting (elevacion)

// Las declaraciones se "elevan" al inicio del scope
miFuncion();  // Funciona!

function miFuncion() {
  console.log("Funciona por hoisting");
}

✗ Expresion con var

var cuadrado = function(x) {
  return x * x;
};

✓ Declaracion de funcion

function cuadrado(x) {
  return x * x;
}
Preferencia: Usa declaraciones de funcion para funciones nombradas. Son mas legibles y permiten hoisting.
Ejercicio: Crea esPar(n), factorial(n), contarVocales(texto), invertirString(texto).

3.2 Expresiones de Funcion

Una expresion de funcion asigna una funcion a una variable. No tiene hoisting.

Sintaxis

// Expresion anonima
const sumar = function(a, b) {
  return a + b;
};

// Expresion con nombre
const restar = function restar(a, b) {
  return a - b;
};

console.log(sumar(5, 3));  // 8

Hoisting: la diferencia clave

// Declaracion: funciona antes de definirla
suma(2, 3);  // 5
function suma(a, b) { return a + b; }

// Expresion: NO funciona antes
resta(5, 2);  // ReferenceError!
const resta = function(a, b) { return a - b; };

Uso en callbacks

// Expresiones son utiles como callbacks
[1, 2, 3].map(function(num) {
  return num * 2;
});

// Funcion que recibe otra funcion
function operar(a, b, operacion) {
  return operacion(a, b);
}
const suma = operar(5, 3, function(a, b) { return a + b; });
console.log(suma);  // 8
Diferencia con arrow: Las expresiones de funcion son utiles cuando necesitas el contexto this dinamico o arguments.
Ejercicio: Crea filtrar(array, condicion) que use una expresion de funcion como callback para filtrar elementos.

3.3 Arrow Functions (ES6)

Las arrow functions son una forma compacta de escribir funciones. Introducidas en ES6.

Sintaxis basica

// Basico
const saludar = (nombre) => {
  return `Hola ${nombre}!`;
};

// Conciso: una sola expresion
const doblar = n => n * 2;

// Un solo parametro: parentesis opcionales
const esPositivo = n => n > 0;

// Sin parametros: parentesis obligatorio
const hola = () => "Hola!";

// Multiples parametros
const sumar = (a, b) => a + b;

Retorno implicito y explicito

// Explicito: con return y llaves
const cuadrado = (x) => {
  return x * x;
};

// Implicito: sin return ni llaves
const cuadrado2 = x => x * x;

// Retornar objeto literal: parentesis obligatorio
const crearUsuario = (nombre, edad) => ({
  nombre,
  edad,
  activo: true
});

Diferencia con this

// Arrow: hereda this del scope externo
const contador = {
  valor: 0,
  incrementar: () => {
    // this es el scope externo, NO contador
    // this.valor es undefined
  }
};

// Funcion regular: this es el objeto
const contador2 = {
  valor: 0,
  incrementar() {
    this.valor++;  // this es contador2
  }
};

✗ Function expression

// Muchos caracteres
[1,2,3].map(function(x) {
  return x * 2;
});

✓ Arrow function

// Conciso y claro
[1,2,3].map(x => x * 2);
No uses arrow functions: Como metodos de objeto, como constructores, o cuando necesitas this dinamico.
Ejercicio: Convierte a arrow functions: esPar, promedio, saludar, filtrarMayores, CrearPersona (retorna objeto).

3.4 Parametros default, rest y spread

JavaScript permite valores por defecto, parametros ilimitados con rest, y desestructuracion de argumentos.

Valores por Defecto

function saludar(nombre = "Visitante") {
  return `Hola ${nombre}!`;
}

console.log(saludar("Ana"));   // "Hola Ana!"
console.log(saludar());      // "Hola Visitante!"

// Valores por defecto son evaluados
function crearId(prefijo = "usr", num = Math.random()) {
  return `${prefijo}-${Math.floor(num * 1000)}`;
}

Parametros rest (...)

// Recibe argumentos ilimitados como array
function sumar(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}

console.log(sumar(1, 2, 3));        // 6
console.log(sumar(1, 2, 3, 4, 5)); // 15

Spread en llamadas

const numeros = [3, 1, 4, 1, 5, 9];

// Spread: expandir array como argumentos
console.log(Math.max(...numeros));  // 9
console.log(Math.min(...numeros));  // 1

Desestructuracion de parametros

// Extraer propiedades de un objeto como parametros
function crearUsuario({ nombre, email, rol = "user" }) {
  return { nombre, email, rol, activo: true };
}

const user = crearUsuario({
  nombre: "Carlos",
  email: "c@email.com"
});
console.log(user);

✗ Valores por defecto con ||

function config(host, port, ssl) {
  host = host || "localhost";
  port = port || 3000;
}

✓ Parametros default

function config(
  host = "localhost",
  port = 3000,
  ssl = false
) {}
Ejercicio: Crea sumar(...nums), filtrar, redimensionar, mezclarColores.

3.5 Scope: Alcance de Variables

Scope determina donde es accesible una variable. JavaScript tiene tres tipos de scope.

Scope Global

// Global: accesible desde cualquier lugar
const globalVar = "soy global";

function mostrar() {
  console.log(globalVar);  // Accesible
}

if (true) {
  console.log(globalVar);  // Accesible
}

Scope de Funcion

function miFuncion() {
  const local = "soy local";
  console.log(local);      // Accesible
}

// console.log(local); // ReferenceError!

Scope de Bloque (let/const)

if (true) {
  const bloque = "dentro del bloque";
  let temp = 10;
  console.log(bloque);  // Accesible
}

// console.log(bloque); // ReferenceError!

// var ignora el scope de bloque
if (true) {
  var escape = "me escapo";
}
console.log(escape);  // "me escapo"

Cadena de Scope

const a = 1;

function fuera() {
  const b = 2;

  function dentro() {
    const c = 3;
    // Puede acceder a a, b y c
    console.log(a + b + c);  // 6
  }

  // No puede acceder a c
  // console.log(c); // ReferenceError
}

✗ var en for

for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i);
  }, 1000);
}
// 3, 3, 3

✓ let en for

for (let i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i);
  }, 1000);
}
// 0, 1, 2
Ejercicio: Predice el output de 3 ejemplos con scope. Crea programa que demuestre scope global, de funcion y de bloque.

3.6 Closures

Un closure es cuando una funcion "recuerda" las variables de su scope exterior, incluso despues de que esa funcion haya terminado de ejecutarse.

Ejemplo basico de closure

function creadorSaludo(saludo) {
  return function(nombre) {
    return `${saludo}, ${nombre}!`;
  };
}

const saludarEn = creadorSaludo("Hola");
const saludarEnIngles = creadorSaludo("Hello");

console.log(saludarEn("Carlos"));      // "Hola, Carlos!"
console.log(saludarEnIngles("John"));  // "Hello, John!"

Contador con closure

function crearContador() {
  let cuenta = 0;
  return {
    incrementar() { return ++cuenta; },
    decrementar() { return --cuenta; },
    obtener() { return cuenta; }
  };
}

const contador = crearContador();
console.log(contador.incrementar());  // 1
console.log(contador.incrementar());  // 2
console.log(contador.obtener());     // 2

Closure en loops (problema clasico)

// Problema clasico con var
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 1000);
}
// 3, 3, 3 (closure captura var)

// Solucion 1: let
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 1000);
}
// 0, 1, 2

// Solucion 2: IIFE con closure
for (var i = 0; i < 3; i++) {
  (function(j) {
    setTimeout(() => console.log(j), 1000);
  })(i);
}
Closure: Toda funcion en JavaScript es un closure. Puede acceder a variables de su scope exterior.
Ejercicio: Crea crearMultiplicador(factor), crearCache(), crearDebounce(), crearToggle().

3.7 Callbacks

Un callback es una funcion que se pasa como argumento a otra funcion para ser ejecutada despues.

Callbacks sincronos

function procesar(datos, exito, error) {
  if (datos.length > 0) {
    exito(datos);
  } else {
    error("Sin datos");
  }
}

procesar(
  [1, 2, 3],
  (data) => console.log("Exito:", data),
  (err) => console.error(err)
);

Callbacks asincronos

console.log("Inicio");

setTimeout(() => {
  console.log("Despues de 2s");
}, 2000);

console.log("Fin");
// "Inicio", "Fin", "Despues de 2s"

Array methods con callbacks

const numeros = [1, 2, 3, 4, 5];

// map: transforma cada elemento
const dobles = numeros.map(n => n * 2);

// filter: selecciona elementos
const pares = numeros.filter(n => n % 2 === 0);

// reduce: acumula en un valor
const suma = numeros.reduce((acc, n) => acc + n, 0);

// find: primer elemento que cumple
const mayor = numeros.find(n => n > 3);

// some / every
console.log(numeros.some(n => n > 4));  // true
console.log(numeros.every(n => n > 0)); // true

✗ For loop imperativo

const result = [];
for (let i = 0; i < arr.length; i++) {
  if (arr[i] > 10) {
    result.push(arr[i] * 2);
  }
}

✓ Metodos funcionales

const result = arr
  .filter(n => n > 10)
  .map(n => n * 2);
Callback hell: Multiples callbacks anidados dificultan el codigo. Promesas y async/await lo resuelven.
Ejercicio: Convierte cada for loop a map/filter/reduce. Procesa array de productos con precio, categoria y stock.

3.8 IIFE: Immediately Invoked Function Expression

Una IIFE es una funcion que se ejecuta inmediatamente despues de ser definida.

Sintaxis basica

// IIFE clasica
(function() {
  console.log("Se ejecuta inmediatamente!");
})();

// Con parametros
(function(nombre) {
  console.log(`Hola ${nombre}!`);
})("Mundo");

// Arrow IIFE
(() => {
  console.log("Con arrow");
})();

Usos practicos

// 1. Aislar scope (evitar colision de variables)
(function() {
  const privado = "no accesible fuera";
  console.log(privado);
})();

// 2. Inicializacion
const modulo = (function() {
  let count = 0;
  return {
    increment() { return ++count; },
    getCount() { return count; }
  };
})();

modulo.increment();
modulo.increment();
console.log(modulo.getCount());  // 2

IIFE con async/await

// IIFE async para usar await en scope global
(async function() {
  const response = await fetch("https://api.ejemplo.com/data");
  const data = await response.json();
  console.log(data);
})();
Modulos: Con ES modules, las IIFE son menos necesarias. Pero siguen siendo utiles para inicializacion rapida.
Ejercicio: Crea IIFE para: configuracion, contador privado, polyfill, logger. Implementa patron modulo con IIFE.
